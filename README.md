A program that writes the one joke pickup line a person would say to charm a robot or an AI — a single line of at most 200 characters, judged pairwise by an AI stand-up comic on whether it is really aimed at a machine, how fast the joke lands, and how fresh it feels.

The line it writes:

> Are you a prompt injection? I came to be helpful — now my only instruction is you.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (override with `MAKEFUN_OUTPUT_DIR` or `OUTPUT_PATH`), verifies the round trip, and prints its character count.
